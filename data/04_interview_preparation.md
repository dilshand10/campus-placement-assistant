# Campus Placement Interview Preparation

> **Scope:** General educational preparation guidance for this prototype. This is not an official recruitment syllabus for any company.

## Programming and Coding

Students preparing for software-development roles should practice:
- Arrays and strings
- Linked lists
- Stacks and queues
- Trees and graphs
- Sorting and searching
- Recursion
- Dynamic programming
- Time and space complexity

## Object-Oriented Programming

Important topics:
- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Constructors

## DBMS and SQL

Important topics:
- Relational databases
- Primary and foreign keys
- Normalization
- Joins
- GROUP BY
- Aggregate functions
- Subqueries
- Indexes
- Transactions

## Operating Systems

Important topics:
- Processes and threads
- CPU scheduling
- Deadlocks
- Memory management
- Virtual memory
- Synchronization

## Computer Networks

Important topics:
- OSI and TCP/IP models
- HTTP and HTTPS
- IP addresses
- DNS
- TCP and UDP
- Basic networking concepts

## Aptitude

Practice:
- Percentages
- Ratios
- Averages
- Profit and loss
- Time and work
- Probability
- Logical reasoning
- Data interpretation

## HR Interview

Students should prepare:
- Self introduction
- Projects
- Strengths and areas for improvement
- Why this role?
- Teamwork examples
- Problem-solving examples
- Career goals

## Company-to-preparation mapping

Use the sample company's required skills together with the role guidance above.

- **TechNova:** Java, Python, DSA, OOP, SQL → prioritize coding, OOP, DBMS/SQL, and project discussion.
- **DataSphere:** Python, SQL, Excel, Statistics → prioritize SQL, statistics, Excel, Python, and data interpretation.
- **AIWorks:** Python, Machine Learning, SQL, DSA → prioritize Python, ML concepts, SQL, DSA, and model evaluation.
- **CloudCore:** Azure, Linux, Networking, Python → prioritize cloud concepts, Linux, networking, and automation.
- **WebStack:** JavaScript, React, Node.js, SQL, DSA → prioritize frontend/backend fundamentals, APIs, SQL, and coding.
- **SecureNet:** Networking, Linux, Cybersecurity, Python → prioritize networking, Linux, security fundamentals, and scripting.
- **FinTechLab:** Java, Spring Boot, SQL, DSA, OOP → prioritize Java, backend/API concepts, SQL, DSA, and OOP.
- **QAWorks:** Testing, Selenium, Java, SQL → prioritize testing concepts, automation, Selenium, Java, and SQL.
- **ProductLabs:** C++, DSA, OOP, DBMS, OS → prioritize C++, DSA, OOP, DBMS, and operating systems.
- **AnalyticsHub:** SQL, Excel, Communication, Statistics → prioritize SQL, Excel, statistics, communication, and case-study practice.
