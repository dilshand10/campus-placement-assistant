# Sample Job Role Guide

> The role descriptions below are simplified educational descriptions for this prototype. They are not official job descriptions.

## Software Developer
**Typical focus:**
- Programming
- Data structures and algorithms
- OOP
- Databases
- Software development

**Relevant preparation:** DSA, coding, OOP, DBMS/SQL, operating systems, projects.

## Data Analyst
**Typical focus:**
- SQL
- Python
- Excel
- Statistics
- Data interpretation

**Relevant preparation:** SQL, statistics, Excel, Python, data interpretation.

## Machine Learning Engineer
**Typical focus:**
- Python
- Machine learning
- Data processing
- Statistics
- Model evaluation

**Relevant preparation:** Python, ML concepts, SQL, statistics, model evaluation, DSA.

## Cloud Engineer
**Typical focus:**
- Cloud platforms
- Linux
- Networking
- Automation
- Infrastructure concepts

**Relevant preparation:** Azure/cloud concepts, Linux, networking, Python/automation.

## Full Stack Developer
**Typical focus:**
- Frontend development
- Backend development
- APIs
- Databases
- JavaScript ecosystem

**Relevant preparation:** JavaScript, React, Node.js, APIs, SQL, DSA.

## Cybersecurity Analyst
**Typical focus:**
- Networking
- Linux
- Security concepts
- Threat awareness
- Basic scripting

**Relevant preparation:** networking, Linux, cybersecurity fundamentals, Python/basic scripting.

## Backend Developer
**Typical focus:**
- Server-side programming
- APIs
- Databases
- Backend frameworks
- Data structures

**Relevant preparation:** Java, Spring Boot, APIs, SQL, DSA, OOP.

## QA Engineer
**Typical focus:**
- Software testing
- Test cases
- Automation
- Selenium
- SQL

**Relevant preparation:** testing, test cases, Selenium, Java, SQL.

## Associate Software Engineer
**Typical focus:**
- Programming fundamentals
- DSA
- OOP
- DBMS
- Operating systems

**Relevant preparation:** C++, DSA, OOP, DBMS, operating systems.

## Business Analyst
**Typical focus:**
- SQL
- Excel
- Statistics
- Communication
- Business problem solving

**Relevant preparation:** SQL, Excel, statistics, communication, case studies.
